# Privacy Statement

This tool is designed to be safe and transparent.

## Data handling

- No account login
- No personal data collection
- No analytics
- No ad tracking
- No hidden background requests beyond normal page loading
- No uploads from the user

## What the tool may do later

If public data imports are added in the future, they should:

- use only public, readable sources
- be documented in the README
- be visible in the source code
- avoid collecting any user-identifiable data

## Security note

A static site cannot be guaranteed "safe" in the absolute sense, but this format minimizes risk because it is:

- inspectable
- reproducible
- frontend-only
- easy to audit
- easy to host publicly
