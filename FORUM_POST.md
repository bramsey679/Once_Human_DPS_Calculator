# Once Human Build/Damage Calculator — community preview

I made a static, open-source Once Human build/damage calculator.

## What it does

- build planning
- weapon / star / tier / calibration inputs
- armor-slot planning for all 6 slots
- mods and cradle perks
- PvE / PvP target selection
- transparent, browser-only UI

## What it does not do

- no login
- no account linking
- no personal data collection
- no executable
- no hidden background services
- no uploads

## Why this should be easy to trust

- source code is public
- it is a static site
- no installer is required
- no privileged permissions are required
- the behavior is visible in the source
