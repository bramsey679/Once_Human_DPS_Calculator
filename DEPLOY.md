# Free deployment checklist

## Recommended path: GitHub Pages

1. Create a public GitHub repository.
2. Upload these files.
3. Enable GitHub Pages in the repository settings.
4. Deploy from the default branch root.
5. Share both:
   - the live GitHub Pages URL
   - the public repository URL

Why this is the best trust path:
- static hosting
- public source code
- no custom domain required
- easy for moderators and players to inspect

## Alternative: Cloudflare Pages

1. Connect the repository.
2. Build with no framework settings needed.
3. Publish the static files.
4. Share the live URL and source repo.

## What to include in the submission package

- README.md
- PRIVACY.md
- a changelog
- screenshot of the UI
- public source repo link
- live demo link
- optional checksum for zip downloads

## What not to do

- do not bundle an .exe unless absolutely necessary
- do not request login
- do not hide the code
- do not add tracking
- do not collect player data
